1. Make the beta invitation-only

Dirty 30 is a closed beta for one committed league. A person who verifies an arbitrary phone number must not automatically receive league access.

Implement an explicit application access state:

PENDING
ACTIVE
DISABLED

Add it to the User model and create a reviewed migration.

Rules:

* The verified BOOTSTRAP_COMMISSIONER_PHONE user becomes ACTIVE commissioner.
* A user whose verified phone matches a valid pending roster invitation may authenticate with PENDING access and accept that invitation.
* Successful invitation acceptance changes access to ACTIVE atomically with membership creation.
* An arbitrary verified phone with no invitation remains PENDING.
* PENDING users can access only:
    * /api/healthz
    * /api/me
    * Invitation acceptance for their own matching verified phone
    * Sign-out
* PENDING users cannot view teams, rosters, schedules, standings, scores, venues, courts or commissioner information.
* DISABLED users cannot access league data or accept invitations.
* Commissioner can disable or restore an account.
* Removing a player from a roster does not automatically delete their account or audit history.
* If the beta policy is that removed players lose all league access, commissioner must explicitly disable them.

Add a mobile “Waiting for an invitation” screen for authenticated PENDING users. It should explain that access requires a captain or commissioner invitation and provide sign-out.

Never expose whether a different phone number has a pending invitation.

DISPUTED
